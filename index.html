Excel VBA · Reconciliation Automation
Automated Vendor & Intercompany Reconciliation Tool
Built a production-grade Excel VBA macro (MACRO_v7) to automate the full intercompany reconciliation workflow between two entities using raw Tally exports. The tool runs a 4-pass matching engine — Invoice + Amount, Narration + Amount, Amount + Date (within 7 days), and Amount Only — applying the core rule that Co1 Debit must equal Co2 Credit. Outputs matched pairs, unmatched ledgers with category breakdowns, and a colour-coded Summary sheet. Handles multi-section Tally data, bill-reference extraction, and duplicate detection automatically.
Excel VBA Tally Export Intercompany Recon Automation
